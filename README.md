# ToolBox

All-in-one offline utility, productivity, converter, calculator, habit tracker, and routine maker app.

View your app in AI Studio: https://aistudio.google.com/app/prompts/03b8fb27-8a79-4d8e-91bc-4bceaddd63e2

## Run Locally

**Prerequisites:** Node.js

1.  **Install dependencies:**
    ```bash
    npm install
    ```

2.  **Set up environment variables:**
    Create a `.env.local` file in the root directory (you can copy `.env.example`) and set your `GEMINI_API_KEY`:
    ```env
    GEMINI_API_KEY="your_api_key_here"
    ```

3.  **Run the app:**
    ```bash
    npm run dev
    ```
